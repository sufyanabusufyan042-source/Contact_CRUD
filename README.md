# Contact CRUD

Contact Management System built with Node.js, Express.js, MongoDB (Mongoose), EJS and Bootstrap. Add, view, edit and delete contacts with pagination. Follows MVC architecture with routes, try/catch error handling, custom 404/500 pages and .env configuration.

## Setup

1. npm install
2. Copy .env.example to .env and fill in PORT and MONGO_URI
3. npm start
